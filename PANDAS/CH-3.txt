Pandas: Summary Functions and Maps — Notes
1. Summary Functions
These give a quick overview/statistics about your data.
describe()
Gives a summary of stats for a column (works differently for numeric vs string data).
reviews.points .describe()
# count, mean, std, min, 25%, 50%, 75%, max
reviews.taster_name.describe()
# count, unique, top, freq
Individual stats
reviews.points.mean()       # average
reviews.points.median()     # middle value 
reviews.points.min()
reviews.points.max()
reviews.points.std()        # standard deviation
unique()
Lists all unique values in a column:
reviews.taster_name.unique()
value_counts()
Shows unique values and how often they occur:
reviews.taster_name.value_counts()

2. Maps — Transforming Data
A map takes one set of values and transforms them into another set, using a function.
map() — works on a Series (single column)
Transforms every value using a function you provide.
review_points_mean = reviews.points.mean()
reviews.points.map(lambda p: p - review_points_mean)
📌 map() returns a new Series — original data is unchanged unless you reassign it.

apply() — works on a DataFrame (row-by-row or column-by-column)
def remean_points(row):
    row.points = row.points - review_points_mean
    return row
reviews.apply(remean_points, axis='columns')
	• axis='columns' → function applied to each row
	• axis='index' → function applied to each column
📌 apply() also returns a new DataFrame — original is unchanged.

3. Shortcut: Built-in Operators
Pandas supports faster built-in math operations directly on columns instead of map/apply:
reviews.points - review_points_mean       # same as using map
Combine two columns:
reviews.country + " - " + reviews.region_1
✅ These are faster than map()/apply() because pandas uses vectorization (optimized under the hood).

4. map() vs apply() — Quick Comparison
Feature	map()	apply()
Works on	Series (one column)	DataFrame (rows/cols)
Input to function	Single value	Entire row/column (Series)
Use case	Transform values in a column	Transform based on multiple columns

✅ Cheat Sheet Summary
Task	Code
Full stats summary	df.col.describe()
Mean	df.col.mean()
Unique values	df.col.unique()
Count each value	df.col.value_counts()
Transform column values	df.col.map(lambda x: ...)
Transform rows using multiple cols	df.apply(func, axis='columns')
Fast built-in math	df.col1 - df.col2

🧠 Example Walkthrough
Goal: Create a new column showing how far each wine's score is from the average.
mean_points = reviews.points.mean()
reviews['points_deviation'] = reviews.points.map(lambda p: p - mean_points)
Goal: Create a combined "star rating" based on points and country (custom logic using multiple columns → use apply).
def get_rating(row):
    if row.country == 'Canada':
        return 3
    elif row.points >= 95:
        return 3
    elif row.points >= 85:
        return 2
    else:
        return 1
reviews['star_rating'] = reviews.apply(get_rating, axis='columns')
