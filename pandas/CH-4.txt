Pandas: Grouping and Sorting — Notes
1. Groupwise Analysis — groupby()
groupby() splits data into groups based on column values, so you can analyze each group separately.
Basic grouping + count
reviews.groupby('points').points.count()
📌 This is basically the same as value_counts(), but groupby is more flexible.
Grouping + other aggregations
reviews.groupby('points').price.min()
➡️ For each points value, find the minimum price.
Grouping + custom function using apply()
reviews.groupby('winery').apply(lambda df: df.title.iloc[0])
➡️ For each winery, get the first wine title listed.
Grouping by multiple columns
reviews.groupby(['country', 'province']).description.agg([len])
➡️ Groups by country AND province together, then counts descriptions in each group.

2. agg() — Multiple Statistics at Once
Instead of calling .min(), .max(), .mean() separately, use agg():
reviews.groupby('country').price.agg([len, min, max])
➡️ Returns count, minimum, and maximum price — all in one table.

3. Multi-Indexes
When you group by more than one column, pandas creates a MultiIndex (index with multiple levels).
countries_reviewed = reviews.groupby(['country', 'province']).description.agg([len])
countries_reviewed.index
Convert back to a regular (single-level) index:
countries_reviewed.reset_index()
📌 Most people prefer a regular index (easier to work with), so reset_index() is commonly used after grouping.

4. Sorting — sort_values()
By default, groupby() output is sorted by the group key, NOT by the values. Use sort_values() to sort by actual data.
Sort ascending (default)
countries_reviewed = countries_reviewed.reset_index()
countries_reviewed.sort_values(by='len')
Sort descending
countries_reviewed.sort_values(by='len', ascending=False)
Sort by index instead of values
countries_reviewed.sort_index()
Sort by multiple columns
countries_reviewed.sort_values(by=['country', 'len'])

✅ Cheat Sheet Summary
Task	Code
Group by 1 column + count	df.groupby('col').col2.count()
Group by 1 column + agg	df.groupby('col').col2.min()
Group by multiple columns	df.groupby(['col1','col2'])
Multiple stats at once	df.groupby('col').col2.agg([len, min, max])
Reset MultiIndex to normal	df.reset_index()
Sort by values (ascending)	df.sort_values(by='col')
Sort by values (descending)	df.sort_values(by='col', ascending=False)
Sort by index	df.sort_index()
Sort by multiple columns	df.sort_values(by=['col1','col2'])

🧠 Example Walkthrough
Goal: Find the best-rated wine for each country, sorted by rating (best first).
best_wine = reviews.groupby('country').apply(lambda df: df.loc[df.points.idxmax()])
best_wine = best_wine.reset_index(drop=True)
best_wine = best_wine.sort_values(by='points', ascending=False)
Goal: Count how many reviews each taster wrote, sorted from most to least.
reviews_per_taster = reviews.groupby('taster_name').size().reset_index(name='count')
reviews_per_taster = reviews_per_taster.sort_values(by='count', ascending=False)
