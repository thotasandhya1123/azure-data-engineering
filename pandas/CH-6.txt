Pandas: Renaming and Combining — Notes
1. Renaming — rename()
Used to change column names or index/row labels — without changing the actual data.
Rename a column
reviews.rename(columns={'points': 'score'})
Rename a row index label
reviews.rename(index={0: 'firstEntry', 1: 'secondEntry'})
📌 Renaming index labels one-by-one is uncommon (use set_index() instead — covered earlier).
Rename axis names (the names of the index/columns themselves)
reviews.rename_axis("wines", axis='rows')
reviews.rename_axis("fields", axis='columns')
📌 rename_axis names the axis itself, not the labels inside it.

2. Combining DataFrames
Three tools to combine data from multiple sources: concat(), join(), merge().
concat() — Stack DataFrames together (same columns)
Used when DataFrames have the same structure/columns and you just want to stack rows.
canadian_youtube = pd.read_csv("CAvideos.csv")
british_youtube = pd.read_csv("GBvideos.csv")
pd.concat([canadian_youtube, british_youtube])
📌 Think of it as "stacking" one dataset on top of another.

join() — Combine DataFrames sharing an index
Used when DataFrames have different columns but a common index you want to match on.
left = canadian_youtube.set_index(['title', 'trending_date'])
right = british_youtube.set_index(['title', 'trending_date'])
left.join(right, lsuffix='_CAN', rsuffix='_UK')
📌 lsuffix / rsuffix are needed when both DataFrames have overlapping column names (to avoid naming conflicts).

3. concat() vs join() — Quick Comparison
Feature	concat()	join()
Combines by	Stacking rows (or columns)	Matching on index
Use case	Same structure, different rows	Different data, shared key/index
Example	Two months of the same CSV format	Two datasets about the same titles

✅ Cheat Sheet Summary
Task	Code
Rename column(s)	df.rename(columns={'old':'new'})
Rename row index label	df.rename(index={0:'new_label'})
Rename axis name	df.rename_axis("name", axis='rows')
Stack DataFrames (same cols)	pd.concat([df1, df2])
Combine on shared index	df1.join(df2, lsuffix='_1', rsuffix='_2')

🧠 Example Walkthrough
Goal: Combine trending YouTube video data from Canada and Britain into one dataset.
canadian_youtube = pd.read_csv("CAvideos.csv")
british_youtube = pd.read_csv("GBvideos.csv")
combined = pd.concat([canadian_youtube, british_youtube])
Goal: Compare Canadian vs British data for the same video titles on the same trending date.
left = canadian_youtube.set_index(['title', 'trending_date'])
right = british_youtube.set_index(['title', 'trending_date'])
combined = left.join(right, lsuffix='_CAN', rsuffix='_UK')
