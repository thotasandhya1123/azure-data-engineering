Pandas: Data Types and Missing Values — Notes
1. Checking Data Types — dtype / dtypes
Single column's type
reviews.price.dtype
All columns' types
reviews.dtypes
📌 Common types: int64, float64, object (usually text/strings), bool, datetime64.
📌 Even numeric-looking columns can be object type if they contain mixed data.

2. Converting Data Types — astype()
Change a column's data type:
reviews.points.astype('float64')
📌 The index also has a dtype, accessible via reviews.index.dtype.

3. Missing Data — NaN
Missing values are represented as NaN (Not a Number), which is always of type float64.
Find missing values — isnull() / notnull()
reviews[reviews.country.isnull()]      # rows where country is missing
reviews[reviews.country.notnull()]     # rows where country is NOT missing
Count missing values
reviews.country.isnull().sum()

4. Filling Missing Values — fillna()
Replace NaN with something else:
reviews.region_2.fillna("Unknown")
📌 Common replacement values: "Unknown", 0, mean/median of the column, etc.
reviews.price.fillna(reviews.price.mean())    # fill with average price

5. Replacing Non-Null Values — replace()
Replace a specific existing value with another:
reviews.taster_twitter_handle.replace("@kerinokeefe", "@kerino")
📌 Useful when a value has changed (e.g., someone renamed their Twitter handle) and you want to update all instances.

🧠 Example Walkthrough
Goal: Find how many reviews are missing a price, then fill those with the average price.
missing_price_count = reviews.price.isnull().sum()
reviews.price = reviews.price.fillna(reviews.price.mean())
Goal: Count how many times each region_1 value appears, replacing missing values with "Unknown".
reviews.region_1 = reviews.region_1.fillna("Unknown")
reviews_per_region = reviews.region_1.value_counts()

⚠️ Common gotcha: NaN values don't equal themselves! NaN == NaN returns False. That's why you must use isnull()/notnull() instead of == NaN.
