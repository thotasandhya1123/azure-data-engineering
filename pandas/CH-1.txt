1. The Two Core Pandas Objects
DataFrame
A table — a collection of rows and columns.
import pandas as pd
pd.DataFrame({'Yes': [50, 21], 'No': [131, 2]})
   Yes   No
0   50  131
1   21    2
📌 Row labels (0, 1...) are called the index. Column values can be numbers, strings, or even lists.
With custom row labels — index parameter
pd.DataFrame({'Bob': ['I liked it.', 'It was awful.'],
              'Sue': ['Pretty good.', 'Bland.']},
             index=['Product A', 'Product B'])

Series
A single column — a sequence of values (like one column of a DataFrame).
pd.Series([1, 2, 3, 4, 5])
With custom index and a name
pd.Series([30, 35, 40], index=['2015 Sales', '2016 Sales', '2017 Sales'], name='Product A')
📌 A Series has a name, but no column name (since it's just one column).

2. DataFrame vs Series — Quick Comparison
Feature	DataFrame	Series
Structure	Table (rows + columns)	Single column (list of values)
Think of it as	A dict of Series	One column of a DataFrame
Has a name?	No (has column names)	Yes

3. Reading Data Files
Read a CSV file
wine_reviews = pd.read_csv("winemag-data-130k-v2.csv")
Check size (rows, columns)
wine_reviews.shape
Preview first 5 rows
wine_reviews.head()
Use an existing column as the index (instead of default 0,1,2...)
wine_reviews = pd.read_csv("winemag-data-130k-v2.csv", index_col=0)
📌 Without index_col=0, pandas creates its own numbered index — even if your CSV already has an ID-like column.

4. Writing Data to a File
Save DataFrame to CSV
animals.to_csv("cows_and_goats.csv")

✅ Cheat Sheet Summary
Task	Code
Create DataFrame	pd.DataFrame({'col1':[...], 'col2':[...]})
Create DataFrame with custom index	pd.DataFrame({...}, index=[...])
Create Series	pd.Series([...])
Create Series with index + name	pd.Series([...], index=[...], name='...')
Read CSV	pd.read_csv("file.csv")
Read CSV using column as index	pd.read_csv("file.csv", index_col=0)
Check shape	df.shape
Preview data	df.head()
Write to CSV	df.to_csv("file.csv")
